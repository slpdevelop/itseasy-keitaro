## 2. Ключевые сценарии

### Сценарий 1: Создание кампании
- Пользователь создаёт кампанию через интерфейс
- Вводит: название, код страны, ID оффера Keitaro
- Система автоматически создаёт два потока:
  1. Поток по стране → редирект на Google
  2. Поток универсальный → редирект на оффер
- Настраивается домен, группа и источник трафика

### Сценарий 2: Редактирование кампании
- Открытие существующей кампании
- Просмотр текущих офферов
- Добавление новых офферов
- Удаление офферов с корректным пересчётом числовых значений
- Отображение актуальных данных после каждого изменения
